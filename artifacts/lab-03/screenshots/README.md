# Lab 3 visual evidence

These images are generated by Playwright; they are repeatable with:

```powershell
npx.cmd playwright test e2e/lab-03/responsive.spec.ts e2e/lab-03/visual-evidence.spec.ts --project=desktop-chrome
```

The browser tests deliberately mock API responses with `page.route()`. They prove UI states and responsive rendering, not a real-server end-to-end session.
